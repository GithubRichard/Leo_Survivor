## 0.9.2 夜间性能优化

- 丧尸寻路分帧轮转，每个显示帧最多推进256个节点，按32个节点一段检查约3毫秒的时间预算；最多8项并行搜索。开发者倍速共用显示帧预算。
- 房屋与装置使用空间索引，视线直接检查完整线段；门开关、建筑被毁与拆建仍读取实时状态，路线和可达性缓存随障碍变化失效。
- 巨弩复用同一轮目标检查，拆墙者先检查最近装置并短暂缓存绕路可达结果，减少重复搜索。

## 0.9.1 开发者工具与试玩修复

- 开始画面点击“开发者试玩”，或游戏中按F2、从暂停菜单选择“开发者模式”。面板支持补满状态、无敌、无限体力、添加物品、指定天数的白天/夜晚、六类刷怪、清场、1/2/5倍速、隐藏屋顶、碰撞框和图层检查传送。
- 开发者进度单独保存，“继续测试存档”恢复；使用过工具的本局一直标记为测试存档，正式存档保留。恢复测试进度后无敌、无限体力、隐藏屋顶和加速默认关闭。
- 后墙采用独立的背景排序，室内后角人物完整显示；前墙仍在室内淡化，房屋正前方与右侧的角色正常显示。
- 升级房门与院门按实际门框端点、高度投影，开关及升级前后保持相同门框尺寸。
- 八方向按屏幕位移等速，保留原水平移动速度，奔跑为步行两倍；修正摇杆方向与动画步伐。为了补偿半俯视压缩，纵向世界坐标位移会更大，原2/4米每秒作为水平移动基准。

## 手机和平板操作

触屏设备自动显示摇杆，也可在开始画面点“触屏操作”手动开启。点选模式、输入名字后点“开始游戏”。横屏视野更宽，竖屏也可以玩。

- 左手拖动摇杆移动；轻推慢走，推到底达到正常移速。
- 右手按住“奔跑”，同时拖动摇杆即可奔跑。
- “交互”对应拆家具、拾取、拆装置和与幸存者交谈。
- “建造”进入部署，“切换装置”更换装置，“确认放置”完成放置；移动摇杆调整站位及朝向。
- “背包”中点物品格或装置配方，再点“部署装置”；“丢弃一份”和“返回游戏”直接点击。
- “地图”查看附近小区；“暂停”停止游戏，点“继续游戏”恢复。
- 支持手机横竖屏、平板、安全区及多点触摸；不支持全屏的浏览器会隐藏全屏按钮。

电脑键盘操作继续可用。背包、地图、交谈、暂停和切到其他应用时停止游戏。尚未在真实手机、平板上试玩；已查看浏览器中的手机横竖屏和平板画面。

### 同一 Wi-Fi 访问

手机上的 `localhost` 指的是手机自身，因此需要使用电脑的局域网地址。局域网服务启动命令为 `python preview-server.py --lan`；电脑WLAN地址当前为 `192.168.1.11`，对应地址 `http://192.168.1.11/survivor`。电脑保持运行，手机/平板连接同一Wi-Fi。地址可能在重新连接网络后变化。

局域网服务已获用户授权并开启。本机入口仍为 `http://localhost/survivor`。局域网模式只提供游戏页面、脚本、样式和美术素材，不提供工作区文件列表。

## 怎样试玩

本地试玩地址：[localhost/survivor](http://localhost/survivor)。也可以直接打开 `index.html`。

本地服务重启命令：`python preview-server.py`。

1. 等待页面显示“美术素材已加载”。
2. 用W或S选择完整一天或快速试玩，输入名字后按E或点开始。
3. WASD移动，Shift奔跑；普通房门和院门会自动开关。
4. 靠近家具按E拆除，获得材料。
5. F进入部署，E切换已解锁的建筑，F确认开始3秒建造；也可从背包“建造”页选取。
6. 靠近自己放置的装置按E拆除，返还全部建造材料。背包空间不足时先腾出空间。
7. Tab打开背包，WASD选择格子，E选择材料；G丢弃一份选中物资，靠近按E捡回。
8. M打开或关闭附近地图。背包、地图和交谈界面会暂停游戏。

更新后如果仍显示旧版本，请使用Ctrl+F5重新加载。0.9支持存档；恢复时使用原来的浏览器和网址。

## 0.7移动动画

- 接入 `art/2d/player-run-v1` 已有的东、南、西、北12张帧图，循环顺序1→2→3→2。
- 按实际移动距离推进动画：步行约5帧/秒，奔跑约10帧/秒；被墙挡住或停止时回到静止姿态。
- 每张帧设置绘制尺寸与头部/脚底锚点，最后20%帧时长加入短过渡，转向保持步伐相位。
- 背包、地图、交谈和窗口失焦时随游戏一起暂停动画。
- 当前斜向使用最近的已有方向；八方向素材完整后可补充对应帧。
- 简短入口为 `http://localhost/survivor`，仅在本机运行。

## 0.6角色遮挡和门高修正

- 站在房屋正前方的玩家、丧尸与幸存者绘制在前墙之后，避免左侧角色被整面墙遮住；室内角色保留前墙遮挡。
- 房门开关高度统一从2.2米降为2米，补齐上方门楣。

## 0.5墙角和家具修正

- 捕兽夹从56×36像素缩至50×32像素，实际触发判定保持原值。
- 后墙纹理只采样可见内墙区域，排除原图片中前墙及墙顶混入的突出部分。
- 室内家具统一绘制在前墙之前，避免靠近前墙的家具浮在墙上。

## 0.4门和道路修正

- 房门开关共用门框锚点及2.2米高度，关闭时覆盖1.6米缺口，打开后保持相同大小。
- 门在前墙之后绘制，避免打开的门扇被墙面遮住；前墙纹理排除原素材内置缺口。
- 院门按两根门柱的脚点投影，对齐院墙缺口两端。
- 道路使用纯路面区域，单段连接相邻路口；标线按世界坐标绘制，去除重复路缘。

## 0.3画面修正

- 院子改为两块草地，恢复第一批三角屋顶。
- 房屋墙面分别按实际10×6米边界绘制，保持竖直；进屋后隐藏屋顶、淡化前墙。
- 房门使用实际1.6米缺口，院门朝向与前院围栏一致。
- 道路交叉口使用裁剪后的道路顶面纹理。
- 捕兽夹显示宽度56像素，大于院墙的46像素。
- 室外掉落物在室内地板区域被遮挡；丢弃位置保持在玩家脚下，避免偏移穿墙。

## 0.2调整

- 接入 `art/2d` 中的PNG，使用四方向玩家和丧尸、门的开关状态、捕兽夹闭合状态及第三批屋顶。
