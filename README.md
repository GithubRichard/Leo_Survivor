# 守到天明 · 初版0.6

## 怎样试玩

用电脑浏览器打开项目中的 `index.html`，也可以使用本地试玩页面。

1. 等待页面显示“美术素材已加载”。
2. 用W或S选择完整一天或快速试玩，按E输入名字并开始。
3. WASD移动，Shift奔跑；普通房门和院门会自动开关。
4. 靠近家具按E拆除，获得材料。
5. F进入部署，E切换捕兽夹或巨弩，F确认放置。
6. 靠近自己放置的装置按E拆除，返还全部建造材料。背包空间不足时先腾出空间。
7. Tab打开背包，WASD选择格子，E选择材料；G丢弃一份选中物资，靠近按E捡回。
8. M打开或关闭附近地图。背包、地图和交谈界面会暂停游戏。

更新后如果仍显示旧版本，请刷新页面；必要时使用Ctrl+F5重新加载。当前版本刷新后重新开始，没有存档。

## 0.6角色遮挡和门高修正

- 站在房屋正前方的玩家、丧尸与幸存者绘制在前墙之后，避免左侧角色被整面墙遮住；室内角色保留前墙遮挡。
- 房门开关高度统一从2.2米降为2米，补齐上方门楣。

## 0.5墙角和家具修正

- 捕兽夹从56×36像素缩至50×32像素，实际触发判定保持原值。
- 后墙纹理只采样可见内墙区域，排除原图片中前墙及墙顶混入的突出部分。
- 室内家具统一绘制在前墙之前，避免靠近前墙的家具浮在墙上。

## 0.4门和道路修正

- 房门开关共用门框锚点及2.2米高度，关闭时覆盖1.6米缺口，打开后保持相同大小。
- 门在前墙之后绘制，避免打开的门扇被墙面遮住；前墙纹理排除原素材内置缺口。
- 院门按两根门柱的脚点投影，对齐院墙缺口两端。
- 道路使用纯路面区域，单段连接相邻路口；标线按世界坐标绘制，去除重复路缘。

## 0.3画面修正

- 院子改为两块草地，恢复第一批三角屋顶。
- 房屋墙面分别按实际10×6米边界绘制，保持竖直；进屋后隐藏屋顶、淡化前墙。
- 房门使用实际1.6米缺口，院门朝向与前院围栏一致。
- 道路交叉口使用裁剪后的道路顶面纹理。
- 捕兽夹显示宽度56像素，大于院墙的46像素。
- 室外掉落物在室内地板区域被遮挡；丢弃位置保持在玩家脚下，避免偏移穿墙。

## 0.2调整

- 接入 `art/2d` 中的PNG，使用四方向玩家和丧尸、门的开关状态、捕兽夹闭合状态及第三批屋顶。
- 玩家步行2米/秒、奔跑4米/秒，丧尸移动1.5米/秒。
- 停止奔跑后2秒恢复1点体力，此后每2秒恢复1点；体力上限沿用初版的10点。
- 背包物资与建造配方显示缩略图。
- 受伤时显示1秒的淡红边框；实际奔跑时显示淡蓝边框，均不影响点击或遮挡画面中心。
- E拆除捕兽夹返还3铁，拆除巨弩返还5木头。
- 丧尸在距玩家80米的圆周上选择可站立位置刷新，排除玩家领地。
- 室内判定增加缓冲边界，外侧靠墙不透视；屋顶按房体墙顶校准；道路顶面分段绘制，交叉口独立绘制。

## 文件用途

| 文件 | 内容 |
| --- | --- |
| index.html / game.css | 页面与界面外观 |
| game.js | 场景绘制、键盘、背包和地图 |
| simulation.js | 移动、体力、丧尸、建造与资源规则 |
| asset-manifest.js | 素材路径和透明图片的可见区域 |
| art-renderer.js | 素材锚点、地面投影、房体和屋顶拼合 |
| 游戏设计文档.md | 已确定的设计与待讨论内容 |
| checks/rules.cjs | 数值与互动回归检查 |
| checks/browser.cjs | 实际浏览器检查与画面截图 |
