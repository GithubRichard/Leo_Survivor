# 幸存者营地美术

依据根目录《幸存者营地体系规则.md》制作，使用内置 image_gen，原生PNG像素与透明通道保持不变。暗灰、暗黄、低饱和、简洁斜俯视。

- [可浏览预览](preview.html)：类别、NPC八向、站立/行走/交互、营业/打烊、逐帧、布局示意。
- 37张新透明PNG，共354个状态帧；最终完整性见validation.json、metadata-validation.json、preview-validation.json。
- 7名NPC各40帧：8方向×站立、行走A、行走过渡、行走B、交互；另7张独立角色头像。
- 武器/食品/药品/器材/种植五类摊位，各营业与遮盖打烊状态；木、铁货架也各有营业/遮盖状态。
- 医务室/器材棚/食堂/寝室/仓库五套分层建筑，各地板、后墙、前墙、屋顶、开门与关门。原生部件需在引擎标定锚点与门铰链，不能假定图片中心直接重合。
- 入口牌、公告板3状态、流动商推车2状态，营地图标、实物交易、委托、包扎、声望、营业与委托状态，另医生包扎3帧。
- [完整提示词](prompts.json)、records/来源记录、manifest.json实际切片、clips.json动作与提交时序、building-layers.json遮挡管理、layout.json世界米布局示例、offer-art-map.json商品/服务对应。
- reuse/与reuse.json原样复用49张已有物品、能源、家具及作物PNG，含32条常驻报价与4条流动报价所需的图标对应；没有新增货币或商品属性。

商品陈列不是可搜索掉落物；营地不是无敌安全区；寝室不提供睡觉跳夜。屋顶/前墙/门独立，进入室内只处理对应遮挡，室内判定仍使用世界区域。营业关店与公共出口通行分别管理。

本次交付美术、索引和接入说明；没有改游戏逻辑或开启已关闭的游戏自动测试。程序员完成实际接入后，才能确认游戏功能已经实现。
