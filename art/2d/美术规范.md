# 2D 美术规范

依据游戏设计文档与本次美术要求，2026年10月11日。

## 风格

- 上帝半俯视，约45度斜俯视；角色与家具保持一致朝向。
- 基础几何形体、少量色块，无精细纹理、木纹或砖缝，面部仅保留最少识别形状。
- 暗灰 #343633、灰 #51534B、暗黄 #8E793E、灰橄榄 #63664C。
- 房屋沿用总文档的红屋顶、白墙：压低饱和度为灰红 #674A40 与灰白 #AAA99A。
- 世界物体使用透明 PNG；界面使用屏幕平面视角。血量使用连续红条 #A5413C，体力使用连续绿条 #4E8051，两者均不分格。

## 房屋层级与视野

建议绘制顺序：地面 → 室内地板 → 后墙 → 家具与角色（按脚底深度排序）→ 前墙 → 屋顶 → 界面。

屋顶必须独立于房屋主体；玩家脚底进入房屋范围时，屋顶透明度降为0，离开后恢复为1。可用约0.2秒过渡作为展示建议。判定由房屋地面范围决定，不应以屋顶图片边界判断。邻居房屋分别管理屋顶。

PNG为独立生成素材，屋顶与房体需在选定引擎中校准位置、缩放和锚点，不能假定两张图片直接重合。高前墙也可能遮挡室内角色，必要时与屋顶一起淡出或拆分墙层。

## 交付边界

本批提供静态美术素材与预览，不包含游戏运行逻辑、行走动作帧或伤害判定。血量与体力图为满槽美术，正式界面应拆为背景和可裁剪的连续填充。数值变化时不得缩放整个边框。

## 第二批更新

新增与替换素材位于 `sprites-v2/`；第一批的其他素材位于 `sprites-v1/`。预览页自动引用新版血量、体力和铁锭，旧角色静态稿仅作对照。

| 文件 | 内容 |
| --- | --- |
| player_east / south / west / north | 玩家东、南、西、北方向 |
| zombie_east / south / west / north | 丧尸东、南、西、北方向 |
| bear_trap_hit | 捕兽夹命中后闭合状态 |
| yard_gate_closed / open | 铁院门关闭、开启状态 |
| house_door_closed / open | 木房门关闭、开启状态 |
| iron | 两条铁锭 |
| health_bar | 无分格连续红色长条 |
| stamina_bar | 无分格连续绿色长条 |

方向采用屏幕坐标：东朝右、南朝下（正面）、西朝左、北朝上（背面），供上帝半俯视场景使用。若引擎地图轴采用等距投影，需要在导入时映射方向名。各方向为独立绘制的朝向图，不是行走动画，也不能用旋转平面图片替代角色转身。

捕兽夹命中图仅表示夹齿闭合，不新增持续困住敌人的规则。院门、房门的开关状态供已有普通门自动开门规则使用，触发与碰撞由游戏逻辑控制。切换图片时保持同一门铰链位置；四方向角色保持同一脚底锚点并校准人物高度，避免切换时跳动。

生成使用内置 image_gen，提示词保存在 `prompts-v2.json`。
