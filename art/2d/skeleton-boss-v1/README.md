# 天气与第二层骷髅美术

按三份源规则制作45张新原生透明PNG、335个状态帧：weather-v1/15张，skeleton-boss-v1/30张。内置image_gen生成，原始PNG像素与透明通道保留；不通过脚本改画。最终完成情况见validation.json、metadata-validation.json与preview-validation.json。

最新用户修订优先：成功离开二层时，仍存活的骷髅实际恢复26血并重置战斗，全部战斗骨头和该层玩家弹体清除；死亡遗骨保留原血量、原位置、剩余复活时间。不是简单重画血条。物品、宝箱领取记录与技能不重置。

- [统一动作预览](preview.html)：分类、八向、动作循环和逐帧；[最终提示词](prompts.json)。
- png/与../weather-v1/png/：新原生素材；records/保存实际提示词、原始来源与SHA256。
- manifest.json / alignment.js：335帧的实际切片矩形与建议中心；不要直接等分原图猜切片。
- clips.json / animation-events.json：动作帧序、释放事件及规则时序；预览FPS不规定战斗时间。
- geometry.json：准确范围的世界单位语义，程序投影绘制；PNG装饰边缘不当碰撞。
- reuse/、reuse.json：6张既有宝箱/作物素材的原样副本与宝箱切片；不重新设计天气专用作物。
- [程序接入说明](程序接入说明.md)：包括离层强制修订；source-documents/为最新规则快照。

普通战斗骨4血，落地竖立，落地10秒后无伤回飞，实际接回才回血。死亡遗骨20血、单根竖立，约角色高，与宝箱分开；完整、裂损和抖动仍是竖立骨，碎裂永久阻止复活。玩家大骨20血、半径1米，飞行结束碎裂，不生成遗骨或地面接触陷阱。

骷髅每方向24状态：待机/3行走/3普攻/4投骨/4横扫/空挥/受击/2解体/接回/缺骨待机与3行走；复活另每方向4状态。玩家每方向6状态，释放、收招、取消均为空手。角色显示比例应以同方向idle/ready/standing标定后固定，不能逐帧按包围框缩放；脚点与手位在引擎校准。

已通过45张PNG原始来源与透明通道、335帧切片、八方向覆盖、动作索引和浏览器预览检查。六张复用素材均与旧版逐字节一致。正式交付以manifest所列文件为准；未采用的旧版原图保留供追溯，程序不要扫描png目录自动导入。本批只交付美术、索引、预览和接入说明；没有修改游戏逻辑，也没有开启已关闭的游戏自动测试。
