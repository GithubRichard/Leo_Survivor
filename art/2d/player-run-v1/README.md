# 主角八方向奔跑

东、南、西、北、东南、东北、西南、西北，每个方向3张透明PNG，共24张。

文件名为 `player_run_方向_01.png`、`02.png`、`03.png`。英文方向名分别为 `east`、`south`、`west`、`north`、`southeast`、`northeast`、`southwest`、`northwest`。

三个姿态为伸展A、收腿过渡、反向伸展B。建议先以 `01 → 02 → 03 → 02` 循环播放，8帧/秒为美术预览速度，不更改游戏的奔跑移动速度与体力消耗规则。预览页可调整播放速度、暂停、逐帧查看。

方向采用屏幕坐标：东向右、南向下（正面）、西向左、北向上（背面）；四个斜向位于其间。若游戏使用等距地图坐标，按摄像机投影映射移动方向。

保留暗黄外套、暗灰上衣与裤子、深色鞋和黑色短发，保持极简几何2D半俯视风格，不增加纹理或装备。

`manifest.json` 记录动画顺序、帧文件、尺寸和建议锚点。`alignment.js` 供预览对齐使用，仅调整绘制位置与尺寸，不改变PNG原图。引擎导入时可使用同样的帧锚点，避免逐帧按轮廓自动缩放造成抖动。

生成工具为内置 image_gen。`prompts.json` 保存每帧提示词；同方向的第2、3帧还以第1帧作为对齐参考，只修改四肢姿态。此批提供动画美术与预览，游戏中的奔跑触发、朝向映射和帧切换由后续代码接入。
