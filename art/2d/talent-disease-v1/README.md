# 开局天赋与疾病图标

依据《开局天赋与疾病规则》v1，制作10项天赋、10项疾病，共20个独立透明PNG。沿用游戏暗灰、暗黄、极简几何风格，每张一个图标；内置 image_gen 生成，保存原生透明通道与像素，未用脚本改画PNG。

20/20张图标、透明通道、来源SHA256、10对双向互斥与唯一编号均已检查通过。浏览器预览20张全部加载，6项筛选、4种展示状态与32像素缩略图检查通过，无页面错误；未执行游戏流程或数值验收。

- [图标预览](preview.html)：按类别或名称浏览，32/64/96/160像素、明暗/棋盘背景、正常/已选/互斥/数量已满状态示意。
- png/：20张最终图标；records/：原生来源、提示词与SHA256。
- [最终提示词](prompts.json)：20项视觉设计、来源效果和互斥对应。
- [图标设计清单](图标设计清单.md)：逐项核对名称、轮廓、效果、互斥项与PNG。
- manifest.json：稳定编号、图标路径、原始尺寸、有效边界和属性语义。
- game-art.js：供程序员接入的只读图标映射，不包含开局选择或结算逻辑。
- validation.json、preview-validation.json：素材与预览验证结果。
- [程序接入说明](程序接入说明.md)：天赋选择流程、显示状态与存档衔接要求。
- source-documents/：原规则快照；项目根目录最新玩法文档为实现依据。

名称、数值、选择勾选、互斥叉号、冷却或禁用状态均不烘焙到位图。已选边框、互斥原因、数量上限由界面叠加；不能仅靠变灰表达禁止原因。预览中的状态可一次作用于全部图标，仅供美术检查，不表示合法搭配。

疾病虚弱使用 frail_constitution，与潜伏者怒吼临时状态 roar_weakness 分开。近视不画模糊或闪屏效果；卡片文字必须明确地面白天18米。PNG仅用于图标展示，不改变真实照明范围或游戏数值。

数值字段只记录v1文档中的增减/倍率语义，不能用旧示例重设正在更新的饱食分档、恢复基准或既有玩家属性。普通菜单不能通过清除图标移除疾病；存读档不能重复叠加特征。
