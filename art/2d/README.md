# 2D 美术素材

依据《游戏设计文档.md》制作，使用内置 image_gen。

统一规范：极简几何2D形体，暗灰、暗黄、低饱和；约45度斜俯视，左上光照，透明PNG背景。界面血量为连续红条，体力为连续绿条，均不分格。

房屋保留暗红屋顶、灰白砖墙。草地采用灰橄榄色和暗黄枯草。

素材清单：house 房屋；grass 草地院子；fence 围栏模块；iron 铁资源；wood 木头资源；metal_cabinet 铁柜；wood_cabinet 木柜；bear_trap 捕兽夹；ballista 巨弩。

铁柜和木柜为尚未明确名称的家具暂定稿。场景可分别摆放2个和3个，不代表新增游戏规则。围栏为拼接模块。房屋60平方米、院子40平方米的设计面积需在后续场景中设定比例。

本批为静态美术素材，捕兽夹张开、巨弩待发射。特殊建筑尚未定义，因此没有添加。

第二批已扩充玩家、丧尸的东南西北朝向，捕兽夹命中后闭合状态，院门与房门开关状态，并将铁锭图改为两条。新版文件见 `sprites-v2/`，其他素材见 `sprites-v1/`。

打开 `preview.html` 查看全部素材，可切换角色方向、门状态、捕兽夹状态与屋顶显示。完整清单和导入规范见 `美术规范.md`，内置 image_gen 提示词见 `prompts-v2.json`。
