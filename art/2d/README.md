# 2D 美术素材

依据《游戏设计文档.md》和《数值与内容扩展方案.md》v1.1制作，使用内置 image_gen。

统一规范：极简几何2D形体，暗灰、暗黄、低饱和；斜俯视，透明PNG背景。血量为连续红条，体力为连续绿条，均不分格。铁资源为两条铁锭。捕兽夹命中状态保留圆形底座，移除原张开夹子。

- [基础素材预览](preview.html)：场景、铁木家具、四向角色、门开关、陷阱状态与屋顶切换。
- [主角八向奔跑](player-run-v1/preview.html)：8个方向，每向3张，共24张；可调速、暂停和逐帧查看。
- [主角持武器动作](player-armed-v1/preview.html)：7种武器×8向，站立、奔跑、攻击共392帧，56张透明图集。
- [停车场、Boss、照明与潜伏技能](parking-boss-v1/preview.html)：115张新透明PNG、803帧，含玩家照明开/关八向站立、奔跑与投灯动作；[接入说明](parking-boss-v1/程序接入说明.md)。
- [扩展素材全集](expansion-v1/preview.html)：146项新增素材，可按类别和名称搜索。
- [扩展美术设计](扩展美术设计.md)：扩展方案与模型、状态、轮廓、图标的对应设计。
- [基础美术规范](美术规范.md)：基础清单与导入约定。

基础第一批位于 sprites-v1，修订与方向素材位于 sprites-v2。扩展资产位于 expansion-v1，实际交付情况以该目录 manifest.json、validation.json 为准。

房屋基体和屋顶独立；玩家进屋时由游戏程序隐藏对应屋顶。模型保留原始PNG透明通道。正式接入需要标定统一显示比例、角色足点和建筑屋顶锚点，配置碰撞和交互状态。
