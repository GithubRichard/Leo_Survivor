# 天气美术

6个独立天气图标，9张天气特效图集，共15张原生透明PNG、30个状态帧。源图在png/；manifest.json独立列出天气帧。统一的提示词、来源、索引检查和交接记录在相邻skeleton-boss-v1/。

[统一预览](../skeleton-boss-v1/preview.html) · [程序接入说明](../skeleton-boss-v1/程序接入说明.md) · [最终提示词](../skeleton-boss-v1/prompts.json)

晴/阴采用现有照明或程序调色，不另画全屏背景。雨丝用于粒子重复，水花短循环；雾为低对比柔边局部纹理，由程序控制可见范围和透明度；雷击与风柱预警有单独材质。不能覆盖HUD或把天气粒子作为实物遮挡。
