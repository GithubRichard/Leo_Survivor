# 玩家持武器动作 v1

使用内置 image_gen，以现有主角和武器为参考生成透明PNG。7类武器：木棍、木矛、铁斧、简易弓、手弩、散弹枪、燃烧瓶。每种8向，每向站立1帧、奔跑3帧、攻击3帧。最终交付56张动作图集，共392帧；另有7张朝南持械站立参考图。

每张图集为3列×3行，按阅读顺序占用第1—7格，末行第2、3格留空：
1站立，2奔跑A，3奔跑经过，4奔跑B，5攻击蓄力/瞄准，6出手/释放，7收招/复位。每帧都包含角色与武器，游戏接入时无需再叠画原背包武器图。

- atlas/：最终56张原生透明PNG图集。
- preview.html：武器、八方向、站立/奔跑/攻击切换，暂停、逐帧、帧率、明暗背景。
- prompts.json / build-atlas-plan.cjs：图集提示词、392帧索引与生成计划。
- manifest.json / alignment.js：逐帧sourceRect、尺寸、可见范围、建议躯干锚点。
- validation.json：完整性、透明通道、7个有效格、2个留空格和原生来源检查。
- clips.json：168个动作片段，按帧ID引用站立、奔跑、攻击顺序。
- metadata-validation.json：方向、动作计数、帧ID、矩形边界、实际提示词和预览语法检查。
- records/：每张原生生成图片的来源和实际提示词。
- individual-reference-plan.json与7个武器文件夹：首批独立站立参考及其原始制作计划；最终动作索引以当前prompts.json为准。

PNG像素及透明通道保持原样。切片通过源图坐标完成，必要时在透明行列间选取切线，避免武器越过理想等分线时切到邻帧；使用manifest.json中的rect，不直接假设图片尺寸可被3整除。躯干锚点用于预览，接入时需按世界比例标定足点与攻击时机。

奔跑建议1→2→3→2；攻击1→2→3后回站立。木棍挥击、木矛突刺、铁斧下劈、拉弓释放、手弩射击、散弹枪后坐复位、燃烧瓶投掷分别表现。远程弹体独立绘制；燃烧瓶释放及收招帧手中无瓶。美术帧率不改变游戏伤害或冷却。此批提供动作素材与预览，游戏运行逻辑另行接入。


验证结果：56/56张图集、392/392帧，透明通道、原生来源、7个有效格、2个留空格与切片间隔检查通过；共168个动作片段。所有PNG由内置 image_gen 生成，未以脚本修改像素。

最终提示词完整保存在 [prompts.json](prompts.json)，修正提示词另见 prompt-revisions.json。切片和锚点以 manifest.json 为准。inspect-atlases.ps1 使用 Windows PowerShell 检查PNG；finalize-metadata.cjs 检查动作索引。旧 inspect-assets.ps1 和 build-plan.cjs 仅对应首批独立参考图，不用于最终图集。

浏览器预览验证：Chrome成功加载全部56张图集，7种武器×3种动作共21个切换组合均通过，8方向画布和逐帧区无脚本错误。结果见 preview-validation.json，截图见 preview-check.png。
