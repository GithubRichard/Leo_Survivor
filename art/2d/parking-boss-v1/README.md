# 停车场、潜伏者Boss与照明/潜伏美术

依据《停车场扩展规则》v1.2与《潜伏者Boss与潜伏技能规则》v1制作。用户补充：Boss潜伏时身体完全埋在地下，不画身体或半露身体；玩家装备照明工具的外观一并提供。所有新位图使用内置 image_gen 生成，暗灰、暗黄、灰橄榄、极简几何2D，保留原生PNG像素与透明通道。

已完成115张PNG、803个状态/动作帧、344组动作序列，另有6个精确SVG范围覆盖层，并附86张保持原像素的既有复用PNG。多帧图集中的每格计一帧，帧数不是独立PNG文件数。validation.json、metadata-validation.json 与 preview-validation.json 均已通过；本次未试玩或验收游戏逻辑。

- [素材与动作预览](preview.html)：分类、八向、状态、动作循环、逐帧、明暗/棋盘背景。
- [规则覆盖核对](规则覆盖核对.md)：逐条对应新素材、复用素材和无需新模型的程序规则。
- [生成提示词](prompts.json)：所有最终图集布局、状态、提示词与参考路径；修订保存在 overrides.json。
- png/：最终原生PNG；records/：来源、实际提示词与SHA256；revisions/：被替换初稿，仅供追溯。
- manifest.json / alignment.js：每帧源图矩形、有效范围和建议对齐中心。使用rect切片，不能假定按图片尺寸直接等分。对齐中心不是碰撞脚点。
- clips.json：按帧ID引用的动作顺序；art-bindings.json：显隐、阶段、灯具兼容与范围等接入提示。
- masks/：圆形照明、70°手电、90°头灯、怒吼2米预警/波纹、基础圆形视野遮罩。SVG负责精确几何，不修改PNG。
- reuse/ / reuse-manifest.json：交付时复制的既有材料、怪物、残骸、操作图标及连续血条等，保持来源像素；完整既有武器动作仍参考此前交付。
- source-documents/：制作依据的两份规则快照。
- [程序接入说明](程序接入说明.md)：给“程序员”任务的交接文件。

prompts.json 是最终制作清单；目录中的历史建表和一次性修订脚本仅供追溯，不要重新执行覆盖清单。程序接入读取 manifest.json、clips.json 与 art-bindings.json。

潜伏者常规/畏缩各8向，每向12格：待机、3移动、3普攻、眩晕、怒吼蓄力/释放、退避、死亡。砸灯者8向每向12格，包含移动、近战、投石准备/释放/收招、退避与死亡。Boss地面痕迹、地裂和现形碎屑均不含潜伏身体。

玩家每方向提供点亮火把/提灯/手电的站立和3帧奔跑，火把/提灯另有准备和释放；佩戴头灯另有站立和3帧奔跑。关灯/无能源版本另有8向，每向4种工具各站立+3奔跑。头灯另提供八向开/关佩戴层，供已有持械动作搭配。玩家潜伏技能另有8向待机、3潜行、启动、中断与结束，始终在地表。

投灯释放时手中无灯，飞行使用独立道具，落地后才建立光区。头灯不占手；单手灯只与徒手、木棍、铁斧兼容。灯具手/头佩戴点和世界足点需要在引擎中校准。美术帧率不规定伤害、冷却和交互时间。

原生PNG可能包含少量装饰光晕；装饰光晕不扩大有效照明，也不参与碰撞。灯光/视野/怒吼/投掷必须由程序按墙、车、封闭门与承重柱裁切。基础可见区不是灯。Boss仅潜伏状态免疫普通伤害；显形、眩晕、蓄力、怒吼、退避与畏缩阶段本身均正常受伤。

本批交付美术素材与预览，游戏运行逻辑由程序员接入。没有用脚本改画或清理PNG像素。inspect-assets.ps1 检查原生PNG透明通道、格数、切片与来源；finalize-metadata.cjs 检查方向/动作/规则索引并生成导入文件；verify-preview.cjs 用浏览器验证预览。验证通过后再打包和通知程序员。
