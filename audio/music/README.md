# 原创游戏轻音乐

三首无歌词原创器乐，2026年11月4日由 compose-music.py 的原创旋律、和声及合成音色离线渲染，无外部采样。

- 晨光：110.667秒，72 BPM，柔和钢琴、铺底和低音。
- 雨窗：124秒，64 BPM，电钢琴感音色与小调和声。
- 静夜守望：132秒，60 BPM，稀疏旋律与空灵铺底。

母带为24kHz、16bit、立体声WAV。每首均有淡入淡出，峰值统一0.65。游玩时顺序轮播，可单独开关、调音量与选曲；暂停、后台及开场动画不播放，电视广播压低音量。所有音频本地播放，不联网生成。

0.14.11新增《危夜围城》：141.143秒、112 BPM，compose-night-music.py原创离线渲染。夜晚自动循环，天亮恢复三首轻音乐；独立开关与音量持续有效。

0.15.2起游戏改为加载同名MP3（LAME VBR质量2，四首合计约4.8MB，原WAV约48.7MB）。WAV保留为可编辑母带，不再打进Docker镜像。重新渲染时 compose-music.py 与 compose-night-music.py 会自动调用 encode-music.py；只想重新压缩时直接运行 `python encode-music.py`，需要本机已安装 ffmpeg。
